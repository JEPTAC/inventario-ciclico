Actualización automática 8:00 a.m.

La app intenta sincronizar automáticamente a las 8:00 a.m. cuando un super admin o jefe logístico tiene la sesión abierta y Drive autorizado.

Para que se ejecute aunque nadie abra la app se necesita backend, Apps Script o Cloud Function programada.
